# Schedule data

The bundled `skills/websummit-planner/assets/websummit.db` contains a snapshot of the publicly accessible Web Summit Lisbon 2026 schedule, collected on 7 November 2026 from websummit.com, for 9–12 November 2026.

Source website: https://websummit.com/
Source endpoint: https://websummit.com/api/list-items/?slug=schedule&typename=DefaultTemplate_Custompage_FlexibleContent_ScheduleList&timezone=Europe%2FLisbon

Session titles, descriptions, speaker names, affiliations, and event branding originate from Web Summit and their respective contributors. The repository's MIT license covers its code and instructions; it does not grant rights in that third-party content. No separate redistribution license for the schedule data has been established by this project. Attribution records the source and does not establish permission or endorsement.

Community side events (7–14 November 2026) were collected from https://side-events-guide.com/ (schema.org event markup). Titles, descriptions, organizer names, prices and links belong to the event organizers and that site; the same terms apply as for the Web Summit data above. Side events are not run or endorsed by Web Summit, and entries may be incomplete or out of date.

The snapshot excludes the original author's personal shortlist, notes, history, custom settings, and filesystem paths. Local use may create a separate personal database that is not part of the shared skill.

This project is unofficial and is not affiliated with or endorsed by Web Summit. Schedules can change; the bundled snapshot is not a live availability or access guarantee.
